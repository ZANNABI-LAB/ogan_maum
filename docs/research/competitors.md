## 반복 불만 Top 5

1. **기기 변경·고장 시 데이터 유실** — "새폰교체후…기록은 사라지고" [P2], "휴대폰을 바꾸면서 자료이전이 안되는데" [P4], 약 5년 기록 복구 불가 [A1]
2. **서버·로그인 의존 불신** — "로그인 강제…서버를 내리면서…데이터도 백업 못했는데" [P1]
3. **엑셀 가져오기·내보내기** [P5][P3][A1]
4. **입력 경직성** — "금액을 안적으면 입력이 안되네요 화환만 보내는 사람" [P2], 정렬·관계·참석 여부 요청
5. **광고 간섭** — "광고 삭제 평생권…추가버튼 누를때 간섭됨" [P3], 연락처·문자 연동 요청

## 대체재

- 카카오페이 송금봉투: 경조사 등 12개 카테고리, 봉투 송금 비중 13%→23%, 50대 이상 증가 [N1][N2]. 보낸 기록 역할을 하지만 사람별 장부 정리는 확인 못함
- 토스: 경조사 장부 기능 확인 못함 [N3]
- 엑셀·메모: 리뷰에 반복 등장 — 경쟁자이자 데이터 유입원

## 수익 모델

- 주류: 무료 + 광고. 일회성 ₩3,300~14,900. 구독 사례 없음
- 유료 백업 후 유실에 대한 분노·환불 요청 [A1]
- 카테고리 규모상 의미 있는 매출은 어렵다 (추정)

## 시장 신호

- 평균 축의금 2025년 11.7만원 (NH농협 이체 533만 건, 40·50대 10.7만원) [N4], 카카오페이 기준 첫 10만원 돌파 [N5]
- 2025 혼인 약 24만 건(+8.1%), 사망 362,968명(+1.2%) [N6]
